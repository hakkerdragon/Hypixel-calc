# Hypixel-calc
Hypixel Skyblock Flips is a live Android economy tracker designed for Minecraft Hypixel Skyblock players. It connects directly to the official Hypixel Bazaar API to help players discover the most profitable flipping opportunities in real time.
Key Features:
•
Live Market Data: Fetches real-time commodity buy/sell prices and weekly volumes.
•
Smart Profit Calculator: Automatically computes net profit margins (factoring in Bazaar taxes) and Return on Investment (ROI %).
•
Instant Filtering & Sorting: Quickly search for specific items and sort them by Profit, ROI %, or Volume using a clean bottom toolbar.
•
Theme Customization: Switch between System, Light, and Dark modes, with support for Material You dynamic colors.
